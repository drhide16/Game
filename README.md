# Martin Games — ancienne adresse

Les jeux ont déménagé sur **https://www.ravail.org**.

Ce dépôt ne contient plus que le panneau de déménagement servi par GitHub
Pages sur https://drhide16.github.io/Game/ : il annonce la nouvelle
adresse, rappelle qu'il faut mettre à jour ses raccourcis, puis redirige.

- `index.html` — le panneau
- `404.html` — le même panneau, servi pour toute adresse inconnue
- `combat/`, `aquad/` — renvoient au panneau (anciens liens profonds)

**Cette adresse s'arrêtera le 1ᵉʳ septembre.**

Le code des jeux et le déploiement vers l'hébergement vivent désormais
dans un autre dépôt. L'historique complet reste consultable ici : rien
n'a été perdu, les fichiers ont seulement été retirés de la branche.
